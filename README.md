# XCopy

Official website and downloads for XCopy, a free macOS clipboard manager.

XCopy is currently free to use. This repository only hosts the public website,
privacy policy, screenshots, and downloadable app package. The application
source code is not open source.

- Website: https://kelvenbit.github.io/xcopy-app/
- Download: https://kelvenbit.github.io/xcopy-app/assets/XCopy.dmg
- Privacy Policy: https://kelvenbit.github.io/xcopy-app/privacy-policy.html
